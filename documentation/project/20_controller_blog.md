# 20. Public Blog & Reader Controller (`BlogController.php`)

## File Location
[`app/Controllers/BlogController.php`](file:///c:/xampp/htdocs/techscout.n/app/Controllers/BlogController.php)

## Handled Actions
- `index()`: Public blog feed with category and tag filtration.
- `show()`: Single article reader displaying dynamic table of contents, author badges, co-authors, reader tips, and nested comment threads.
- `category()`, `tag()`: Filtered article listings by category or tag slug.
- `trending()`: Top trending articles ranked by views and upvotes.
