# 21. AI Directory & Affiliate Link Controller (`DirectoryController.php`)

## File Location
[`app/Controllers/DirectoryController.php`](file:///c:/xampp/htdocs/techscout.n/app/Controllers/DirectoryController.php)

## Handled Actions
- `tools()`, `toolSingle()`: AI Tools directory list and detail views.
- `prompts()`, `promptSingle()`: AI Prompts directory list and single prompt view with copy-to-clipboard functionality.
- `gpts()`, `gptSingle()`: Custom GPTs directory list and detail views.
- `campaigns()`, `campaignSingle()`, `submitCampaignProject()`, `voteCampaignSubmission()`: Hackathon campaigns and community project submissions.
- `jobs()`, `jobSingle()`, `applyJob()`: Tech job board and job applications.
- `affiliateRedirect()`: Handles `/go/{slug}` outbound affiliate link click tracking.
