# 19. Author Creator Studio Controller (`AuthorStudioController.php`)

## File Location
[`app/Controllers/AuthorStudioController.php`](file:///c:/xampp/htdocs/techscout.n/app/Controllers/AuthorStudioController.php)

## Handled Actions
- `dashboard()`: Creator dashboard, 20-sublevel tier gauge, published article list, earnings preview.
- `articles()`, `createArticle()`, `saveArticle()`, `editArticle()`: WYSIWYG article editor supporting `.docx` document parsing and draft management.
- `tools()`, `prompts()`, `gpts()`: Creator submission interfaces for directory listings.
- `analytics()`: Detailed creator pageview traffic charts.
- `earnings()`: Financial earnings ledger, balance breakdown, and withdrawal payout claim form.
- `coAuthors()`, `inviteCoAuthor()`: Invites co-authors and manages revenue splits.
