    feat(prompts-pricing): separate text vs image prompts, add prompt CRUD image upload, integrate real-time crypto pricing APIs, and on-chain payment verification
    
    - Prompt Architecture Segregation:
      * Non-destructive migration prompts_and_pricing_upgrade.sql adding prompt_type ENUM('text', 'image')
      * DirectoryController and Content model now segregate text prompts (/prompts) from image prompts (/prompts/images)
      * Text prompts strictly render blueprint terminals with no image attachments (featured_image_url = NULL)
      * Image prompts prominently display output artwork and preview modal
    
    - Enhanced Prompt CRUD & Author Studio:
      * Admin prompts CRUD updated with segmented type selector, direct drag-and-drop image upload to /storage/uploads/prompts/, AI model tags, and live syntax validation
      * Author Studio editor updated with prompt type selector and conditional showcase media upload
    
    - Real-Time Live Pricing APIs (PricingEngine):
      * Built PricingEngine service with CoinGecko API integration and Binance API failover
      * Site settings caching with configurable TTL and baseline fallback spot rates
      * Added public API route /api/v1/pricing/crypto-rates and admin test endpoint /api/v1/pricing/test
      * Admin Advertisements tab enhanced with live pricing engine configuration and ping diagnostic tool
    
    - Decentralized Payment Transaction Verification (TransactionVerifier):
      * Built TransactionVerifier service supporting BTC (Mempool.space), ETH (Etherscan), TRON/TRC20, and SOL (Solscan/RPC)
      * Live on-chain transaction hash format validation and ledger query
      * Updated public Crypto Payment Box with live coin conversion rates, dynamic QR codes, and instant on-chain TXID verification badge
      * Added Forensic On-Chain Transaction Inspector modal to Admin Advertisements & Sponsorships for 1-click approvals/rejections
