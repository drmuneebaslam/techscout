    feat(timezone): implement automatic visitor timezone detection and dynamic timestamp localization across admin console
    
    - Enhanced DateHelper with toDateTime(), iso8601(), render(), and renderTwoLines() converting stored Pakistan Standard Time (Asia/Karachi, UTC+5) to visitor's detected timezone
    - Implemented client-side automatic timezone detection via Intl.DateTimeFormat().resolvedOptions().timeZone with cookie persistence and window.localizeAllTimestamps() DOM synchronization
    - Replaced raw PHP date() calls with DateHelper::render across system logs, audit logs, users, dashboard, newsletters, revenue, firewall, media, moderation, content queue, and api keys
    - Updated forensic error inspectors in system logs and audit logs to dynamically parse timestamps with UTC+5 offset and render in local time
    - Preserved dual-theme support using semantic CSS classes (.ts-time-part, .ts-date-part, .ts-tz-abbr) and CSS custom properties without hardcoded tag styles
    - Documented MISTAKE-22 in docs/MISTAKES_LEARNED.md
